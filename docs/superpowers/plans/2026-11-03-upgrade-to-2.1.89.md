# 升级到 Claude Code 2.1.89 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把本仓库从 2.1.88 源码升级到 2.1.89，并交付一套 2.1.90+ 可复用的恢复流水线。

**Architecture:** 先建 `scripts/upgrade/`（inventory / align / extract / probe / verify），用 2.1.88 bundle+map 与 2.1.89 bundle 产出差异台账；再按台账分批移植 `src/` 行为；最后用静态对账 + external 冒烟完成三层验证。

**Tech Stack:** Bun、TypeScript compiler API、`source-map`、`ws`（CDP）、zod、bun:test。

**Spec:** `docs/superpowers/specs/2026-11-03-upgrade-to-2.1.89-design.md`

## Global Constraints

- 目标版本 `2.1.89`；参照 `cli.js`（2.1.88，14,756,533 bytes）+ `cli.js.map`；目标 `package/cli.js`（13,081,065 bytes，SHA-256 `a9950ef6407fdc750bddb673852485500387e524a99d42385cb81e7d17128e01`）。
- 格式：无分号、单引号、2 空格、120 列（oxfmt 强制）。
- 相对导入必须带 `.js` 扩展名。
- 特性开关必须写成字面量 `feature('NAME')`，不得包裹/计算。
- 流水线只读 bundle、只写输出目录，**永不修改 `src/`**。
- 依赖版本与第三方代码不追（`ignored-dependency`）。
- 不得删除 ant-only / 内部代码；目标缺失的标 `retained-internal`。
- 提交信息用 conventional commits，直接提交到 `main`。
- 完成前必须：`bun run typecheck`、`bun run fmt:check`、`bun run lint`（只看本次改动文件）、`bun test`。

## Review Focus

1. **`defer` 不得污染权限规则**：普通 permission rule / settings 仍只能接受 `allow|deny|ask`；只有 PreToolUse hook 输出接受 `defer`。（Task 16 测试）
2. **`defer` 只在 headless 单工具调用时暂停**：交互 TUI 与含兄弟工具调用的批次不得暂停。（Task 17 测试）
3. **`cleanupPeriodDays: 0` 必须校验失败**，不能静默关闭持久化；错误提示指向 `--no-session-persistence`。（Task 18 测试）
4. **`MCP_CONNECTION_NONBLOCKING` 只影响 `-p`**：交互模式仍等待 MCP；未设置或为假时行为不变。（Task 20 测试）
5. **无 map 的对齐不得把第三方字符串归到一等源码**；`verify` 对未登记的移除必须失败。（Tasks 4、7 测试）

import { expect, test } from 'bun:test'
import ts from 'typescript'
import { fingerprintFunction } from '../fingerprint'

function firstFn(code: string) {
  const sf = ts.createSourceFile('x.js', code, ts.ScriptTarget.Latest, true, ts.ScriptKind.JS)
  let found: ts.Node | undefined
  const visit = (n: ts.Node) => {
    if (!found && (ts.isFunctionDeclaration(n) || ts.isFunctionExpression(n) || ts.isArrowFunction(n))) found = n
    n.forEachChild(visit)
  }
  visit(sf)
  return found!
}

test('stable across identifier renames', () => {
  const a = firstFn('function foo(x){return x+"lit"}')
  const b = firstFn('function bar(y){return y+"lit"}')
  expect(fingerprintFunction(a)).toBe(fingerprintFunction(b))
})

test('differs when literals differ', () => {
  const a = firstFn('function foo(x){return x+"one"}')
  const b = firstFn('function bar(y){return y+"two"}')
  expect(fingerprintFunction(a)).not.toBe(fingerprintFunction(b))
})
