Sobird

Remote control for Claude Code

暖石底 #c96442 + 奶油前景 #f6f5f2，对比 3.58:1，满足图形 3:1 阈值。标志由三部分构成：终端提示符 >（发起）、三个分离的点（进行中）、右上角星火（远端 AI）。浅/深背景共用同一枚满底图标。

几何与安全区

主图标画布 64×64，圆角 15（约 23%）。所有部件在 16px 下仍能分辨：提示符描边 7.5；三点半径 3、间距 8.5、基线 y=44.5；星火中心 (48.5, 24.5)，半径 6.4，内凹比 0.22。最远点距圆心 r≈24.1。

最小尺寸

  • 完整标志：≥ 24px 使用完整版（提示符 + 三点 + 星火）；导航栏固定 20px。
  • 16px favicon：用简化版，只留「> + 星火」，去掉三点，避免糊成一团。
  • 系统图标：iOS 180、Android 512、maskable 512，均按「导出」规则生成。
  • 留白：标志四周至少留出 1/4 画布宽的空白，不与文字或边框贴边。

颜色

单一强调色 + 暖石中性色。品牌色只用于图标底、关键强调与小面积高亮；大面积背景用表面色，保证长时间阅读不刺眼。

字体与字标

字标用 Lora 600（Title Case「Sobird」），界面正文用 Poppins，中文字体回落到 PingFang SC，代码与终端输出用等宽字体。

角色 字体 用法
字标 / 标题 Lora 600 「Sobird」始终 Title Case；标题与品牌语境的大字。
界面正文 Poppins 400 / 500 / 600 按钮、标签、正文；字重不超过 600。
中文回落 PingFang SC 与 Poppins 混排时保持行高一致。
代码 JetBrains Mono 终端、路径、命令；不用于品牌字标。
  • 字标组合：图标与文字间距约 0.35 倍文字高度；不要压缩字距或拉伸字体。
  • 副标题：「Remote control for Claude Code」以小号大写字母、宽字距呈现，不抢字标。

应用示例

同一枚图标在真实界面里的样子；Android 使用 80% 内缩的 maskable 版本铺进裁切形状，iOS 使用不透明的 180px 圆角图标。

动效原则

系统启动屏与主屏图标都不能动；呼吸效果只放在 App 加载完成后的产品界面。三版共用同一套静态几何，只改节奏；系统开启「减少动态效果」时全部静止。

iOS PWA 启动屏
静态 PNG

只有 apple-touch-startup-image，按设备尺寸一张张声明；不支持 SVG、CSS、视频。

主屏 / favicon
静态位图

iOS、Android 主屏图标与浏览器 favicon 都不播放动画，也不读取 SVG 内的 CSS 动画。

产品内界面
可动画

加载遮罩、思考指示、连接状态都能用 CSS/SVG 动效，这里才是呼吸灯生效的地方。

  • 推荐搭配：思考/执行用 A（顺序呼吸），加载/连接遮罩用 B（整体呼吸）；C 留给多阶段加载，别在常驻导航栏里播放。
  • 节奏：周期 1.4–2.6s，不要更快；导航栏保持静态，只在真实等待态动画。
  • 降级：prefers-reduced-motion: reduce 下停掉全部动画，保留静态图标。

启动屏视觉规范

iOS 是「你给图」，按机型出静态 PNG；Android 由浏览器按 manifest 现画，一套图标通吃。两端都只显示静态画面。

构图对比

  • 构图：用「图标在上、名称在下」。主屏图标本来就是图标压名称，启动页沿用同一心理模型；并排更像网站页头，纯图标最安静但少了名称确认。
  • 动效衔接：静态启动图交给系统 → App 挂载后若网关/会话还没就绪，再显示产品内呼吸遮罩，就绪即淡出，不做固定延时。
  • 深色模式：media 可以带 prefers-color-scheme，但跟随的是系统外观而非 App 内主题，且需要额外一套图；规范允许但默认可不做。

导出规则

同一份矢量稿，按用途导出不同形态。核心区分：UI 内嵌用圆角，交给操作系统的图标一律方形满底、不透明、圆角由系统切。

用途 形态 要求
UI 内嵌 / 网页 SVG · rx 15 带圆角的满底图标；导航栏、登录页、页脚统一使用。
favicon ICO 16/32/48 16px 用简化版（> + 星火），32px 起用完整版；均满底。
iOS 主屏 PNG 180 × 180 方形、满底、不透明、无圆角；系统自己切圆角。
Android 启动器 PNG 512 × 512 方形满底；maskable 版本内容内缩到 80% 安全区。
启动屏 PNG 各机型 尺寸 = CSS 宽高 × DPR；底色 #efeee9；内容按启动屏构图规范摆放。
分享卡 PNG 1200 × 630 cream 底 + 品牌组合 + 终端示意；以绝对 URL 引用。
主题图标（可选） PNG 512 · monochrome 单色前景、透明底，供 Android 13 主题图标使用。

用法禁区

可以

  • 在浅色或深色表面上使用满底图标，保持同一几何。
  • 按用途选择圆角版（UI）与直角版（系统图标）。
  • 用 maskable 版本铺进任意裁切形状。
  • 在真实等待态使用 A/B 动效，并尊重 reduced-motion。
  • 小尺寸时切换到 16px 简化版。

不要

  • 拉伸、压扁、旋转图标或字标。
  • 更换底色、给标志加描边、阴影、渐变或发光。
  • 把三点合成短杠、移动星火位置或改变内凹比。
  • 在品牌色以外的低对比背景上叠加标志。
  • 给主屏图标、favicon 或启动图加动画。
  • 把整枚标志缩到 16px 以下仍要求完整细节。
